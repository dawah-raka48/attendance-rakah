# نظام الحضور والانصراف – جمعية الراكة

واجهة أولية عربية لإدارة الموظفين وسجلات الحضور وتقارير الشفتات.

## مواعيد الدوام الافتراضية
- الشفت الصباحي: 09:00 إلى 11:30
- الشفت المسائي: 16:00 إلى 21:00

## تشغيل النسخة الأولية
افتح `index.html` محليًا أو فعّل GitHub Pages من:
Settings → Pages → Deploy from a branch → main → /(root).

## الوضع الحالي
- لوحة تحكم وإحصائيات مبنية على بيانات تجريبية.
- إدارة موظفين محلية.
- إضافة سجلات حضور تجريبية.
- تصفية تقارير وتصدير CSV.
- إعدادات الشفتات وسماحية التأخير.
- الوضع الليلي.

**تنبيه:** هذه نسخة واجهة تجريبية فقط. البيانات تحفظ في Local Storage على نفس المتصفح والجهاز، ولا يوجد تسجيل دخول أو قاعدة بيانات مركزية أو تكامل مع جهاز ZKTeco حتى الآن. لا تستخدمها لحفظ بيانات موظفين حقيقية.

## خطة التطوير
1. إضافة خدمة خلفية وقاعدة بيانات مركزية وصلاحيات موثوقة.
2. بناء محرك احتساب كامل للحضور والغياب والإجازات والانصراف.
3. إضافة تصدير PDF وExcel.
4. ربط جهاز ZKTeco بعد التحقق من رقم الموديل ووسيلة الاتصال.
